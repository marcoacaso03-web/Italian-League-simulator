# Contesto: aggiunta leaderboard a Italian League Simulator

## Stack
- Next.js 15 (App Router), TypeScript, Tailwind CSS, pnpm
- Firebase Firestore già configurato nel progetto
- Deploy su Vercel
- Progetto su Replit

## Feature da implementare: Leaderboard globale senza account

### Flusso utente
1. Utente finisce una partita (SimScreen → ResultsScreen)
2. Se il suo score è in top 50, gli viene proposto di salvarlo
3. Inserisce un nickname libero → il sistema genera un codice "NICK#XXXX"
   salvato in localStorage (la sua identità permanente sul device)
4. Lo score viene salvato su Firestore
5. Può vedere la classifica globale top 50

### Schema Firestore
Collection: leaderboard/{docId}
  nickname: string       // es. "ROSSI#4821"
  score: number          // punteggio calcolato (vedi formula)
  overall: number        // TeamOverall.overall (0-99)
  points: number         // punti finali stagione simulata
  position: number       // posizione finale in classifica Serie A (1-20)
  formation: string      // es. "4-3-3"
  difficulty: string     // "easy" | "normal" | "hard"
  showRatings: string    // "on" | "off" (blind mode)
  eraFrom: number        // anno inizio era selezionata
  eraTo: number          // anno fine era selezionata
  timestamp: Timestamp

### Formula score
score =
  (points × 100)
  + (20 - position) × 50
  + (overall × difficultyMultiplier)

difficultyMultiplier:
  hard:              1.8
  normal + blind:    1.5
  easy + blind:      1.0  (stesso di normal senza blind)
  normal:            1.0
  easy:              0.5

### Regole leaderboard
- Solo top 50 score salvati (controllare prima del write se il minimo top50 viene superato)
- Un device può aggiornare il proprio score se migliora (match su nickname in localStorage)
- Leaderboard ordinata per score DESC

### File da creare
1. lib/leaderboard.ts
   - submitScore(payload) → scrive su Firestore se in top 50
   - getLeaderboard() → legge top 50 ordinati per score
   - getUserCode() → legge/genera il codice NICK#XXXX da localStorage
   - calcScore(params) → formula score

2. app/api/leaderboard/route.ts (opzionale)
   - GET → restituisce top 50
   - POST → valida e scrive score

3. app/leaderboard/page.tsx
   - Pagina pubblica con classifica top 50
   - Colonne: rank, nickname, score, overall, punti, formazione, difficoltà, era

4. Modifica app/game/ResultsScreen.tsx
   - Aggiungere sezione submit score con input nickname
   - Mostrare se il risultato è in top 50
   - Link alla pagina leaderboard
